# Idaho Motorcycle Exam — Study App

A local React app to help you study for the Idaho motorcycle knowledge test.

## Quick Start

### Option A — Run the pre-built version (fastest)
Open `dist/index.html` directly in your browser. No install needed.

> Note: Some browsers block local font loading from file:// — if fonts look off, use Option B.

### Option B — Run the dev server (recommended)
1. Make sure you have [Node.js](https://nodejs.org) installed (v18+)
2. Open a terminal in this folder
3. Run: `npm install`
4. Run: `npm run dev`
5. Open `http://localhost:5173` in your browser

### Option C — Serve the built version locally
1. Run: `npm install`
2. Run: `npm run preview`
3. Open `http://localhost:4173`

## What's Inside
- **Study Guide** — 8 tabbed sections covering all key topics
  - Fees & Licensing, Gear & Equipment, Bike Controls
  - Lane Positions (with visual diagram), Braking, Hazards
  - S.I.P.D.E., Idaho Laws, Flash Cards (24 cards)
- **Practice Test** — 25 random questions from a pool of 50
  - Question nav dots, instant feedback, review mode
  - Pass with 20/25, same as the real Idaho exam

## Based On
2025 Idaho Motorcycle Rider's Handbook (July 2025)
Published by Idaho Transportation Department (ITD)
